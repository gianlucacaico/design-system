Agentic workflows

Skills, harnesses and hooks

The reusable parts behind how this site and its design system get built, checked and kept true. Each one is written as a plain template that works with any agent tool, not just the one used here.

Open the library See the governance

Four kinds of part

{{ all.size }} templates

The names are tool-agnostic. Any agent setup has a place for each, whatever it calls them.

SkillA named procedure an agent follows when askedThe steps, the rules and where to stop.{{ skills.size }} in the library
HarnessAn automated run of checks that passes or failsSo nobody has to eyeball it.{{ harnesses.size }} in the library
HookA point where something fires by itself, or plugs inAt a set moment, without being asked.{{ hooks.size }} in the library
WorkflowSkills, harnesses and hooks chained togetherWith a person approving at the gate.{{ flows.size }} in the library
