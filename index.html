Imagery

No stock photos

Three kinds of image, all drawn in the system's own colours, glass and type. Each one shows real content from where it sits, never decoration.

Post artwork

One illustration per post, used three ways: the banner under the title, the thumbnail in post lists and the featured card, and the image people see when the post is shared.

  1. Keep what matters in the middle 80%. The featured card trims the sides.
  2. Keep the bottom-left corner clear. The Featured label sits there.
  3. Draw the post's actual idea. Ink background, colour fields, glass panels and Inter, using only words, figures and labels from the post.
  4. Check it small. It has to read as a thumbnail as well as a banner.

Project pictograms

Each project's key artefact, drawn for the right side of its card at full height and cropped by the card's edges. The eye goes from the client's name, to the pictogram's focal point, to the labels, with no frame or tile around it. The tints are under Colour, in Artwork.

  1. Name corner stays clear: x under 40, y under 56.
  2. Label corner stays clear: x under 110, y over 112.
  3. One focal point, fully inside. Draw big and let context run off the right, top or bottom edge, fading in from the left. A half-cut icon reads as a mistake.
  4. White, then one tint. White for main shapes, white at 20 to 45% for secondary ones, and exactly one tint for the insight, picked to contrast with the card.
  5. No words or figures. Only what the card itself already says.

Client names

Project cards write the client's name as text, top left, rather than showing its logo. A logo needs the client's formal permission, so the written name is the default.

  • Name as text. White and bold, top left of the card's art, clear of the pictogram.
  • Logos only with formal permission. If a client ever gives it: use the brand's own white version, never recoloured, stretched or redrawn, about 18 to 32px high, with the name as alt text.

Use it anywhere

One line

The kit is one stylesheet hosted here. Paste it into any page or prototype that takes HTML and it picks up this look.

  1. 1

    Add the look

    Paste this line inside the page's head. Colours, type, buttons, glass and cards come with it. Version 1 only ever gets changes that won't break your page; anything bigger would arrive as version 2 at its own address.

    <link rel="stylesheet" href="{{ '/v1/gc.css' | absolute_url }}">
  2. 2

    Add the interactions

    Only needed for segmented controls. Everything else works without it.

    <script src="{{ '/v1/gc.js' | absolute_url }}" defer></script>
  3. 3

    Make it yours

    Your playground settings, ready to paste after the first line.

    <style>
  :root{
    --accent:#635BFF;
    --accent-deep:#4B44D6;
    --accent-2:#EB5D76;
    --round:1;
    --glass-blur:20px;
  }
</style>
  4. 4

    Copy the components you need

    Every component in the demo has its code underneath, ready to paste.
